Установка

Для установки FuturaOS скачайте ISO-образ с страницы загрузки и запишите его на USB-накопитель объёмом не менее 8 ГБ.

Команда для записи через терминал Linux/macOS:

dd if=FuturaOS_2.5_amd64.iso of=/dev/sdX bs=4M status=progress

Замените /dev/sdX на ваш USB-накопитель. После записи перезагрузите компьютер и выберите загрузку с USB.

P2P магазин приложений

P2P магазин использует IPFS и DHT для распространения приложений. Для установки пакета:

  1. Откройте P2P App Store из меню приложений
  2. Найдите приложение или вставьте magnet-ссылку / CID
  3. Нажмите «Установить» — клиент загрузит и верифицирует пакет

Пример magnet-ссылки: magnet:?xt=urn:btih:futura_editor_latest

Терминал

FuturaOS поставляется с bash 5.2 и полным набором POSIX-утилит. Стандартные команды Linux работают без изменений:

  • ls, cd, grep, find — файловые операции
  • gcc, make, python3 — разработка
  • systemctl — управление службами

Пакетный менеджер

Команда futura-pkg управляет пакетами из P2P-каталога:

  • futura-pkg install <имя> — установка
  • futura-pkg remove <имя> — удаление
  • futura-pkg update — обновление всех пакетов
  • futura-pkg search <запрос> — поиск

Безопасность

Все пакеты подписываются цифровыми ключами разработчиков. Система проверяет подпись перед установкой. Рекомендуется включить автоматические обновления безопасности в Центре управления.

Лицензия

FuturaOS — проприетарное программное обеспечение. Бесплатно для домашнего использования. Коммерческое использование требует отдельной лицензии. Подробности — на futuraos.ru.

Документация FuturaOS 1.0

Краткое руководство по установке, настройке и использованию.

Установка (Live USB)

Скачайте ISO-образ с страницы загрузки. Для записи используйте Rufus (рекомендуется) или любой другой инструмент для записи ISO.

Как правильно записать образ (Rufus):

  1. Выберите USB-накопитель (все данные на нём будут удалены).
  2. Укажите скачанный ISO-образ.
  3. Схема раздела: выберите GPT.
  4. Целевая система: выберите UEFI (не CSM).
  5. Нажмите «Старт» и выберите «Запись в DD-образе».

Предупреждение: Все данные на USB-накопителе будут безвозвратно удалены.

После записи перезагрузите компьютер, войдите в меню загрузки (обычно F12) и выберите загрузку с USB.

Оконный менеджер (WM)

FuturaOS поддерживает три режима работы с окнами. Переключение происходит через терминал командой:

wmctl mode <режим>

  • wayland — классический плавающий режим (по умолчанию).
  • tiling — строгая сетка для максимальной продуктивности.
  • infinite — бесконечный масштабируемый холст с космическим фоном.

Терминал и полезные команды

Откройте терминал (Ctrl+Alt+T или иконка на рабочем столе). Доступные команды:

  • sysinfo — информация о системе и загрузке CPU.
  • web-browser — запуск браузера (рекомендуется запускать с интернетом).
  • file-browser — файловый менеджер.

Примечание: Wi‑Fi на железе находится в стадии доработки. На эмуляторах (QEMU/VirtualBox) интернет работает через эмуляцию Ethernet.

Игры и приложения

На рабочем столе расположены иконки Doom и Quake. Они устанавливаются по клику:

  • Двойной клик по иконке → автоматическая установка и запуск игры.
  • При повторном клике игра запускается без повторной установки.
  • Игры запускаются без необходимости ввода команд в терминале.

Бесконечный холст (Infinite Mode)

В режиме infinite фоном служит живая солнечная система.

  • Зум: используйте колёсико мыши для приближения и отдаления.
  • Панорамирование: зажмите среднюю кнопку мыши и двигайте курсором.

Совместимость с железом

  • Поддерживаются UEFI и Legacy BIOS.
  • USB-порты 3.0 работают стабильно; порты 2.0 — в стадии тестирования.
  • Мышь и клавиатура работают через USB.

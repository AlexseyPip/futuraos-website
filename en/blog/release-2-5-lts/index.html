FuturaOS 2.5 LTS — stable release

May 15, 2025 · Alexsey_Pip · Release

We are pleased to announce FuturaOS 2.5 LTS — the first release with long-term support through 2028. This is a stable version for everyday use on home and work computers.

What's new

FuturaWeb V8 12.5 — updated browser with improved JavaScript performance (+18% in Speedometer 3.0), WebGPU, and WebCodecs support.

P2P store 2.0 — new catalog interface, delta package updates, and improved digital signature verification.

Gaming mode — Vulkan and DirectX optimization via Proton with reduced input latency.

Images are available on the download page: AMD64 ISO, ARM64 Preview, and Live USB.

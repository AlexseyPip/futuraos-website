ARM64 Preview for Raspberry Pi

April 3, 2025 · Alexsey_Pip · Announcement

FuturaOS is now available for ARM64 devices in Preview mode. The first build has been tested on Raspberry Pi 4 and Pi 5.

Supported devices

Raspberry Pi 4 (4 GB+), Raspberry Pi 5, and virtualization on Apple Silicon via UTM/Parallels for testing.

Preview limitations

The ARM64 build is under active development. Some features (gaming mode, hardware video acceleration) may be unstable. Feedback is welcome via GitHub.

ARM64 Preview для Raspberry Pi

3 апреля 2025 · Alexsey_Pip · Анонс

FuturaOS теперь доступен для ARM64-устройств в режиме Preview. Первая сборка протестирована на Raspberry Pi 4 и Pi 5.

Поддерживаемые устройства

Raspberry Pi 4 (4 ГБ+), Raspberry Pi 5, а также виртуализация на Apple Silicon через UTM/Parallels для тестирования.

Ограничения Preview

ARM64-сборка находится в стадии активной разработки. Некоторые функции (игровой режим, аппаратное ускорение видео) могут работать нестабильно. Обратная связь приветствуется через GitHub.
